後半部分容易出錯指南

  • Anchor (錨點) 是絕對坐標還是相對坐標？

    這是在 Webots 最容易搞混的地方。

    HingeJoint 的 anchor 是相對於父節點 (Parent Solid) 的坐標系，但通常建議在建模時透過 Pose 將子節點的原點移動到關節處，這樣 anchor 就可以保持 0 0 0，會比較好管理。

    影片中的做法：右臂的第一個關節 anchor 設為 0.2 0 0，這是因為它是直接掛在 Robot (原點) 下面，所以必須手動指到右邊底座的位置。

  • SolidReference 的限制

    它只能用在 endPoint。

    被參照的物件 (LINK3) 必須已經存在且有定義 DEF。

    連接的兩端都必須有 Physics 屬性，否則約束力 (Constraints) 無法建立。

  • Z-Fighting (重疊閃爍) 與碰撞

    因為這是 2D 平面繪圖機，所有連桿都在 XY 平面上。

    為了不讓連桿互相穿透，Z 軸的高度層級 (Layering) 很重要。

    例如：左臂 Z=0.03，右臂 Z=0.05，連結處 Z=0.04。手動調整這些微小的 Z 值，能讓模擬更穩定且視覺更正確。
