製作過程簡述

第一階段：建立基礎機器人與底座 (Base Setup)

  1. 建立 Robot 節點：

    新增一個 Robot 節點。

    注意：務必確認 Robot 的 translation 是 0 0 0，這是整個模型的絕對原點。

  2. 建立底座外型：

    在 Robot 的 children 下新增 Shape -> Cylinder (圓柱)。

    設定尺寸：半徑 0.02，高度 0.02。

    關鍵細節：Webots 的幾何中心預設在物體正中心。因此圓柱有一半會埋在地下。

    修正步驟：修改 Shape 的 translation，將 Z 軸設為 0.01 (高度的一半)，把它「提」到地面上。

  3. Supervisor 設定：

    如果這個機器人未來需要畫線（如標題 Plotter），需要將 supervisor 欄位設為 TRUE。

第二階段：建立第一節手臂 (Link 1) 與馬達

  1. 新增關節 (HingeJoint)：

    • 在 Robot 的 children 下新增 HingeJoint。

    • 參數設定：展開 jointParameters，確認 anchor (錨點) 為 0 0 0。將 axis (旋轉軸) 改為 0 0 1 (繞 Z 軸旋轉)。

  2. 加入馬達 (Motor)：

    • 在 device 欄位新增 RotationalMotor。

    • 重要：將馬達 name 命名為 "T1" (程式碼控制時會用到)。

  3. 建立連桿實體 (Solid)：

    • 在 endPoint 新增 Solid。

    • 定義形狀 (DEF)：為這個 Solid 的 Shape 定義名稱 (如 LINK_SHAPE)，方便後面重複使用。

    • 外型設定：Box，尺寸設為 X=0.02, Y=0.2 (長度), Z=0.02。

  4. 修正連桿位置 (Offset)：

    • 注意：連桿中心點在 (0,0,0)，這樣旋轉時會像螺旋槳一樣中間旋轉。我們希望它像手臂一樣繞著端點轉。

    • 修正步驟：將 Solid 內部的 Shape 沿 Y 軸移動 0.1 (長度 0.2 的一半)。這樣旋轉中心 (Joint) 就會位於連桿的起始端。
