製作過程簡述

第一階段：建立基礎機器人與底座 (Base Setup)

  1. 建立 Robot 節點：

    新增一個 Robot 節點。

    注意：務必確認 Robot 的 translation 是 0 0 0，這是整個模型的絕對原點。

  2. 建立底座外型：

    在 Robot 的 children 下新增 Shape -> Cylinder (圓柱)。

    設定尺寸：半徑 0.02，高度 0.02。

    關鍵細節：Webots 的幾何中心預設在物體正中心。因此圓柱有一半會埋在地下。

    修正步驟：修改 Shape 的 translation，將 Z 軸設為 0.01 (高度的一半)，把它「提」到地面上。

  3. Supervisor 設定：

    如果這個機器人未來需要畫線（如標題 Plotter），需要將 supervisor 欄位設為 TRUE。

第二階段：建立第一節手臂 (Link 1) 與馬達

  1. 新增關節 (HingeJoint)：

    在 Robot 的 children 下新增 HingeJoint。

    參數設定：展開 jointParameters，確認 anchor (錨點) 為 0 0 0。將 axis (旋轉軸) 改為 0 0 1 (繞 Z 軸旋轉)。

  2. 加入馬達 (Motor)：

    在 device 欄位新增 RotationalMotor。

    重要：將馬達 name 命名為 "T1" (程式碼控制時會用到)。

  3. 建立連桿實體 (Solid)：

    在 endPoint 新增 Solid。

    定義形狀 (DEF)：為這個 Solid 的 Shape 定義名稱 (如 LINK_SHAPE)，方便後面重複使用。

    外型設定：Box，尺寸設為 X=0.02, Y=0.2 (長度), Z=0.02。

  4. 修正連桿位置 (Offset)：

    注意：連桿中心點在 (0,0,0)，這樣旋轉時會像螺旋槳一樣中間旋轉。我們希望它像手臂一樣繞著端點轉。

    修正步驟：將 Solid 內部的 Shape 沿 Y 軸移動 0.1 (長度 0.2 的一半)。這樣旋轉中心 (Joint) 就會位於連桿的起始端。

第三階段：撰寫控制器並測試 (Controller)

  1. 關聯控制器：

    在 Robot 的 controller 欄位選擇 New...，建立 Python 控制器。

  2. 撰寫程式碼：

    獲取馬達：motor = robot.getDevice("T1")

    角度轉換：Webots 使用弧度 (Radian)。需將角度 (如 90度) 乘上 3.14159 / 180。

    設定位置：motor.setPosition(1.57) (讓它轉 90 度測試)。

  3. 測試：存檔並執行模擬，確認手臂是否有正確轉動。

第四階段：建立第二節手臂 (Link 2) —— 最困難的部分

這裡不能直接加 Joint，因為 Link 2 與 Link 1 之間有特定的設計角度 (69.62度)，且位置在 Link 1 的末端。

  1. 使用 Pose 節點進行坐標轉換：

    在 Link 1 的 children 下，不要直接加 HingeJoint，而是先加一個 Pose 節點。

    位移 (Translation)：將 Pose 移動到 Link 1 的末端 (Y=0.2)。

    旋轉 (Rotation)：設定 Pose 的 rotation 為 0 0 1 (Z軸)，角度設為 -1.215 (即 -69.62 度轉為弧度)。

    這一步是為了建立一個新的「局部坐標系」，讓接下來的關節長在這個歪斜的方向上。

  2. 新增第二個關節：

    在這個 Pose 的 children 下，才新增 HingeJoint (J2)。

    設定馬達 name 為 "T2"。

  3. 建立 Link 2 實體：

    在 endPoint 新增 Solid。

    外型：長度為 0.27。

    修正位置：將 Shape 沿 Y 軸移動 0.135 (0.27 的一半)，確保旋轉點在端點。

第五階段：建立第三節手臂 (Link 3) 與重複使用

  1. 重複 Pose 轉換技巧：

    • 在 Link 2 的 children 下，新增 Pose。

    • 位移至 Link 2 末端 (Y=0.27)，旋轉角度設為 -79.51 度 (需換算弧度)。

  2. 重複使用形狀 (USE)：

    • 新增 HingeJoint (J3) 與 Solid。

    • 在 Shape 欄位，不需要重新設定 Box 尺寸。直接使用 USE 功能，選擇之前定義好的 LINK_SHAPE (如果尺寸相同) 或者 Link 2 的形狀定義。

    • 影片中 Link 3 長度與 Link 2 相同 (0.27)，所以可以直接 USE Link 2 的定義，省去設定時間。

前半部分容易出錯指南

  • 幾何中心 vs. 旋轉中心：

    這是新手最常錯的地方。Webots 的 Box 或 Cylinder 幾何中心預設在正中間。

    解決法：要在 Solid 下層的 Shape -> transform (或 translation) 做偏移。千萬不要移上面的 Joint 或 Solid 本身，否則旋轉軸心會跑掉。

    口訣：Joint 永遠在 (0,0,0)，是 Shape 自己移出去讓 Joint 在邊緣。

  • Pose 節點的重要性：

    當手臂不是「直直的」連接（有轉折角度）時，必須用 Pose 包住下一層的 Joint。

    如果不加 Pose 直接旋轉 Joint 的軸，會導致馬達的 0 度位置錯誤，後續寫程式控制逆運動學 (Inverse Kinematics) 會非常痛苦。

  • 物理屬性 (Physics & BoundingObject)：

    雖然教學前半段只畫形狀，但若要讓手臂真的「動」起來且有碰撞效果，每一個 Solid 都必須設定：

    boundingObject：通常直接引用 (USE) 該 Solid 的 Shape。

    physics：設為 Physics 節點（使用預設值即可），否則它會變成靜態物體，浮在空中無法受力轉動。

  • DEF / USE 的命名習慣：

    養成好習慣，第一次建立某個零件（如螺絲、連桿）時用 DEF 命名。

    後面要用到一模一樣的零件時用 USE，這樣改一個參數全部都會跟著改，且模擬效能較好。

第六階段：準備工作與定義關鍵節點 (Preparation)

在開始做右邊手臂之前，必須先整理左邊的架構，並為關鍵部位命名，以便稍後「參照」回來。

  1. 清理測試元件：

    將之前為了測試左臂動作而寫的暫時性 Python 程式碼移除，或將馬達歸位。

  2. 定義連接目標 (DEF LINK3)：

    非常重要：找到左臂最末端的 Solid（也就是 Link 3）。

    在該 Solid 的 DEF 欄位輸入名稱，例如 LINK3。

    目的：Webots 的結構是單向樹狀的，稍後右臂要「連回」左臂時，必須透過這個 DEF 名稱來找到它。

  3. 建立右側馬達座：

    複製左側的底座（Static Base），貼上一個新的。

    將新底座沿 X 軸移動 0.2 公尺（設定 translation x: 0.2）。

    為了視覺區分，可以修改 Appearance 的顏色（例如改為藍色）。
